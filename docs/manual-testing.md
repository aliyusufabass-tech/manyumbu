# Manual Testing

Before release, validate these flows on staging:

- Registration, email verification, login, refresh, password reset, and Google auth.
- Profiles, follows, privacy settings, posts, comments, reports, stories, highlights, reels, and admin moderation.
- Private messaging, message requests, read/delivery receipts, reports, and WebSockets.
- Groups, invitations, join requests, group messages, notifications, and group WebSockets.
- Calls, signaling, moderation, professional accounts, verification requests, appeals, and restrictions.
- Data export request and account deletion request/cancel.
- Backup creation, backup verification, and restore into staging.
