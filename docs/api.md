# API Reference

Base path: `/api/v1/`.

Phase 8 production-readiness endpoints:

- `GET /health/`
- `GET /health/live/`
- `GET /health/ready/`
- `GET /api/v1/data-export/`
- `POST /api/v1/data-export/`
- `GET /api/v1/account-deletion/`
- `POST /api/v1/account-deletion/`
- `DELETE /api/v1/account-deletion/`

Earlier accepted APIs remain under auth, profiles, relationships, posts, stories, reels, conversations, messages, groups, notifications, calls, professional accounts, verification, moderation, and admin moderation/report queues.
